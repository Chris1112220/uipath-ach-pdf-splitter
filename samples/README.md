# Sample data (100% fictional)

Everything in this folder is made up. The bank name, companies, identification numbers, account
number, trace numbers, invoice numbers and amounts were generated by
[`tools/generate_sample_report.py`](../tools/generate_sample_report.py) for demonstration only.
No production report, payer, or bank data is included in this repository.

## Input

`input/ACH_Remittance_Report 20260831.pdf`: one combined report, 6 pages, 5 transactions.

| # | Originator (fictional) | Amount | Pages | Why it's in the sample |
|---|---|---|---|---|
| 1 | Northwind Traders | $1,250.00 | 1 | simple single-page transaction |
| 2 | Contoso Medical Supply | $18,420.75 | 2 | single page, more remittance lines |
| 3 | Fabrikam Facilities Services | $7,305.10 | 3-4 | **multi-page transaction**: no `END OF TRANSACTION` on page 3 |
| 4 | Adventure Works / Cycles | $640.00 | 5 | name contains `/`, which is illegal in Windows filenames |
| 5 | Tailspin Toys Foundation | $25,000.00 | 6 | large amount with thousands separator |

The filename carries the report date (`20260831`), which the bot turns into the dated output folder.

## Expected output

`expected-output/2026-08-31/`:

```text
001 - Northwind Traders - $1,250.00.pdf
002 - Contoso Medical Supply - $18,420.75.pdf
003 - Fabrikam Facilities Services - $7,305.10.pdf      (pages 3-4 kept together)
004 - Adventure Works Cycles - $640.00.pdf             ('/' sanitized)
005 - Tailspin Toys Foundation - $25,000.00.pdf
```

These files were produced by the offline simulator, [`tools/simulate_split.py`](../tools/simulate_split.py),
which ports the workflow's parsing rules to Python. Running it a second time on the same PDF prints
`Skipping already-processed source PDF`, because the report's SHA-256 is already in the manifest.
